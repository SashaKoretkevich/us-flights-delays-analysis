# Анализ авиаперелётов США и Random Walk Metropolis

Работа с 30,6 млн записей о рейсах по США за 2004–2008 годы: факторы задержек, влияние возраста самолётов и модель вероятности ухода рейса на запасной аэродром. Плюс отдельная часть — реализация алгоритма Random Walk Metropolis с диагностикой сходимости. Курсовая работа ST2195 «Programming for Data Science», University of London (LSE).

Все задачи решены **дважды и независимо — на Python и на R**, результаты сопоставлены.

## Часть 1. Random Walk Metropolis

Сэмплирование из распределения Лапласа `f(x) = ½·exp(−|x|)`:

- Алгоритм реализован на логарифмической шкале, чтобы избежать численных ошибок при малых вероятностях
- 10 000 итераций, шаг s = 1: оценка среднего 0,019 и стандартного отклонения 1,49 против теоретических 0 и √2 ≈ 1,414
- Диагностика сходимости по статистике R-hat на четырёх цепях из разных стартовых точек: при s = 0,001 значение R-hat ≈ 100 (цепи не перемешиваются), сходимость достигается при s ≥ 0,2

## Часть 2. Задержки рейсов

Данные: пять годовых файлов + справочники аэропортов (3376 записей) и бортов (5029 записей).

**Подготовка:** отфильтрованы отменённые рейсы, приведены типы, извлечён плановый час вылета, выполнены джойны со справочниками, отброшены записи с некорректным возрастом судна и малочисленные группы.

**Выводы:**

- **Лучшее время для перелёта:** раннее утро (03:00–05:00) во все пять лет; худшее — вечерние слоты, когда накапливаются задержки предыдущих рейсов. Лучший день недели — суббота, худшие — четверг и пятница
- **Возраст самолёта:** в 2004–2006 значимой связи с задержками нет, в 2007–2008 связь значима и умеренно сильная (r ≈ 0,61–0,65, p < 0,001). Вывод зависит от периода наблюдения и не является общим законом
- **Модель диверсий:** логистическая регрессия по каждому году для редкого события (доля диверсий 0,197–0,243%) с балансировкой весов классов и стандартизацией признаков. Доминирующий предиктор — расстояние рейса (коэффициенты 0,28–0,40), поздний плановый прилёт увеличивает риск, календарные признаки и координаты аэропортов почти не влияют
